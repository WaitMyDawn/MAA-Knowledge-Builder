# Legacy Word fixture

`simple.doc` is an unmodified Apache POI test fixture, downloaded from https://raw.githubusercontent.com/apache/poi/trunk/test-data/document/simple.doc on 2026-10-25. It is used to verify the binary Word parser; the Apache POI repository distributes its test materials under the upstream license and notices: https://github.com/apache/poi/blob/trunk/LICENSE .

Other DOCX, PDF and image fixtures are generated in temporary directories by the tests.
