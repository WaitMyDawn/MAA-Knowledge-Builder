# 人工复核后的工作流与评测修订

## 已确认结论

Q1、Q2、Q6 不通过；Q3、Q4、Q5、Q7、Q8 通过。结论对应先前保存的具体回答，不覆盖原始自动报告，也不自动套用于新回答。详见 [人工判定](../human-review-decisions-20261011.md)。黄金集升级到 v8，保留 50 道题。

## 检索与回答

- Wiki 抓取主题显式加入页内检索，而不是因子问题字符串与主题键不一致落到全库语义搜索。获取问题提高“自然生成”章节相关性。Q3 原始获取题的六个片段确实未包含展示框段落；同一轮另一道鞘翅合成题含该段，说明正文抓取成功，选段未覆盖。
- 攻略先提供实际准备、阶段动作、危险应对；同一目标的多种手段只算一个维度，属性表不算实际操作。回答 Agent 在合成时检查完整度；仅宽泛攻略/玩法且已有证据的回答再进行一次有界完整度核验及修订。简单问题不增加此调用；不循环重写，也不追加网站抓取。
- 已核对的领域关系可指向攻略主题；关系只存来源，不存预制答案或评测题号。末影龙使用 Wiki 的“教程/打败末影龙”。无预置关系的宽泛问题由有界补检索选择主题。答案仍须读取正文。
- 材料/获取补证仅扩展一轮。直接掉落生物通过正文关系及同模组实体目录匹配；其他材料缺口由一次有界规划选择，最多三个支撑对象，名称必须在当前证据中出现。新增支撑正文不再触发第二轮。全部抓取沿用页面与向量缓存。
- 龙心读取心脏条目之外的源生物死亡与搜刮章节，明确最后一轮及尸体/骨架区别。
- 攻略检索为选中短块附加同一网页、同一章节的前后块，恢复条件句，避免把栖息阶段免疫误读成飞行阶段免疫；嵌入短块、身份及持久缓存不变。
- 当前 Wiki 教程出现了新版矛战术。根据 Mojang 的 [Java 1.21.11 发布说明](https://www.minecraft.net/en-us/article/minecraft-java-edition-1-21-11)，安装版早于 1.21.11 时明确排除该物品及关联玩法。这只是已确认的原版物品版本边界，未更改移植模组默认继承原作知识的策略。

## 来源链接与历史

来源唯一的正文名称及标题自动转为 Markdown 链接；优先匹配长名称，保留已有链接、代码与 URL，同名多来源不自动选择。不会以可能被模板污染的“主要名称/次要名称”覆盖页面名称。

JavaFX 行内、表格、标题渲染可点击 HTTP/HTTPS 链接，拒绝文件与脚本协议。链接作为回答文本保存到历史 JSON，不依赖临时实体映射；保存/加载和重复处理有回归测试。旧历史中原本没有链接的文本不会被批量改写。独立 JavaFX 核验程序实际检查了标题、表格、正文三处 Hyperlink：首次渲染和历史保存/重载后均为三个，且都有点击事件。该核验没有打开外部浏览器。

## 判分

超过五条 required 内容覆盖断言时，允许数量上达到 80%；异常、禁止编造等硬性断言不参与放宽。报告仍保留单项失败和 allRequiredPassed 的原始事实。Q1 独立用六类操作至少四类的断言，不按篇幅判通过。规则匹配可见文本，去掉链接目标和强调标记，避免链接长度或 Markdown 导致误判。

Q5 的人工通过保留，相关断言按语义维度合并；野生龙不能常规驯服保留核心硬约束，完整繁殖条件保留为质量加分。参考答案、要点及裁判要求同步调整，避免只改 rubric 而仍被旧参考答案迫使所有细节必答。宽松数量政策不能替代核心事实正确性。Q7 允许按生存/创造分支说明，Q8 不要求额外完整流体链。参考答案不是完整网页事实的替代，裁判须依据实际提供的证据。
